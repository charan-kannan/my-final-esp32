# **App Name**: GuardianAngel AI

## Core Features:

- Sensor Data Display: Display real-time data from multiple environmental sensors (gas, air quality, EM radiation, humidity, temperature, noise, light) on a web-based dashboard. Each sensor's name, value, and risk level will be clearly highlighted.
- Color-Coded Risk Levels: Implement a color-coded system to indicate the risk level of each sensor reading. Green for safe, yellow for caution, and red for danger.  If the reading is 'SAFE' then don't color-code it.
- Live Graphs: Generate and display live graphs for each sensor reading to visualize trends over time.
- Alert System: Provide a push alert based on hazardous conditions based on environmental input from the different sensors.
- Voice Companion AI Bot: Integrate a voice-interactive AI bot, 'Nova,' that serves as a personal friend. The AI tool is responsible for status updates, safety warnings, and providing emotional support through empathetic conversations.
- Settings Panel: Provide panels for calibration, customization, adjustments, and user profiles.
- Voice Interaction: Enables users to interact with the dashboard and the AI assistant Nova through voice commands.

## Style Guidelines:

- Primary color: Electric blue (#7DF9FF) for a modern and futuristic aesthetic, similar to what the user provided.
- Background color: Dark navy blue (#0B0B45) to enhance contrast and readability.
- Accent color: Neon green (#39FF14) for alerts, highlights, and CTAs to draw attention.
- Body and headline font: 'Space Grotesk' sans-serif for a computerized, techy, scientific feel; consider 'Inter' sans-serif as the body font if longer text is needed
- Use glowing, minimalist icons related to each sensor reading for clear visual representation.
- Implement a card-based layout with rounded edges, inspired by the original image, for a premium and organized appearance.
- Use smooth transitions and subtle animations on data updates to provide a visually appealing and responsive experience.
